# Exploratory Data Analysis — Scripts 01–06

Run these read-only scripts first to understand the Gold Layer before drawing conclusions.

| Script | Topic | Main output |
|---|---|---|
| 01 | Database exploration | Gold objects, columns, row counts and sample records |
| 02 | Dimensions exploration | Distinct customer/product attributes and dimension profiles |
| 03 | Date range exploration | Sales date coverage, customer age and product date coverage |
| 04 | Measures exploration | Baseline sales, order, customer, product and quantity measures |
| 05 | Magnitude analysis | Revenue, customer and product comparisons by dimension |
| 06 | Ranking analysis | Top/bottom products, subcategories and customers |

All scripts use T-SQL and the `Datawarehouse Analytics` database. They query the existing Gold Layer views and do not modify source data.
